# 📘 Lesson 3 – *A kedvenc országom*

**My favorite country**

## 🎯 Objectives

By the end of this lesson, you'll know how to:

* use **kedvenc** (favorite),
* describe with **adjectives**,
* form the **plural**,
* use the **possessive** (my, mine),
* understand **vowel harmony** in Hungarian.

---

## 1️⃣ The word **kedvenc** – "favorite"

In Hungarian:

> **kedvenc** = favorite

It's almost always used with a **possessed noun**.

| English | Hungarian |
| ----------------- | ---------------------- |
| my favorite country | **a kedvenc országom** |
| my favorite city | **a kedvenc városom** |
| my favorite café | **a kedvenc kávézóm** |

Structure:

> **a kedvenc + noun + possessive**

Examples from the texts:

* **A kedvenc országom Kanada.**
* **A kedvenc országom Olaszország.**
* **A kedvenc városom Velence.**

---

## 2️⃣ The possessive: "my / mine"

In Hungarian, you don't put *my* before the noun:
you add an ending to the word.

### Possessive 1st person (I → my/mine)

| Noun | Meaning | My |
| ------- | ---------- | ------------- |
| ország | country | ország**om** |
| város | city | város**om** |
| barát | friend | barát**om** |
| egyetem | university | egyetem**em** |

Examples:

* **a kedvenc országom**
* **a barátom**
* **a kedvenc városom**

---

## 3️⃣ Adjectives from the texts

Here are the important adjectives:

| Hungarian | English |
| -------- | ---------- |
| gyönyörű | magnificent |
| nagy | big |
| magas | tall/high |
| széles | wide |
| szép | beautiful |
| régi | old/ancient |
| modern | modern |
| híres | famous |
| kiváló | excellent |

Examples:

* **gyönyörű tengerpartok** (magnificent beaches)
* **nagy erdők** (big forests)
* **régi épületek** (old buildings)
* **kiváló egyetemek** (excellent universities)

👉 In Hungarian, **the adjective doesn't change in the plural**.

---

## 4️⃣ The plural

The plural is formed with **-k**

| Singular | Plural |
| --------- | ------------- |
| város | város**ok** |
| park | park**ok** |
| iskola | iskola**k** |
| kávézó | kávézó**k** |
| templom | templom**ok** |
| egyetem | egyetem**ek** |

Examples from the texts:

* **parkok**
* **kávézók**
* **éttermek**
* **múzeumok**
* **templomok**

---

## 5️⃣ Vowel harmony (very important)

In Hungarian, suffixes change according to the vowels in the word.

### Two types of vowels

| Type | Vowels |
| ----------- | ---------------------- |
| **back** | a, o, u, á, ó, ú |
| **front** | e, i, ö, ü, é, í, ő, ű |

---

### Example with plural

| Word | Vowels | Plural |
| ------- | -------------- | ------------- |
| város | a, o (back) | város**ok** |
| park | a (back) | park**ok** |
| iskola | a, o (back) | iskola**k** |
| egyetem | e, e (front) | egyetem**ek** |
| templom | o (back) | templom**ok** |

---

### Example with possessive

| Word | Vowels | "my" |
| ------- | ----------- | ------------- |
| ország | a (back) | ország**om** |
| város | a (back) | város**om** |
| egyetem | e (front) | egyetem**em** |
| gyerek | e (front) | gyerek**em** |
