# 📘 Lesson 8 – *Az étteremben*

**In the restaurant**

## 🎯 Objectives

By the end of this lesson, you'll know how to:

* name common **foods and drinks** in Hungarian,
* use the **accusative case** (-t suffix) for direct objects,
* **order food and drinks** politely,
* distinguish **szeretem** (I like it) from **szeretek** + infinitive (I like to...),
* ask about **prices** and pay the bill.

## 2️⃣ The accusative case – the **-t** suffix

In Hungarian, the **direct object** (the thing you eat, drink, want, or order) takes the **accusative suffix -t**.

### How to form it:

| Noun ending | Rule | Example |
| ----------- | ---- | ------- |
| vowel | add **-t** | kávé → kávé**t** |
| consonant (back vowels: a, o, u) | add **-ot** | bor → bor**t**, kenyér → kenyere**t** |
| consonant (front vowels: e, i, ö, ü) | add **-et** or **-öt** | leves → leves**t** |

### Common examples:

| Base form | Accusative | English |
| --------- | ---------- | ------- |
| kávé | kávét | coffee (ACC) |
| bor | bort | wine (ACC) |
| sör | sört | beer (ACC) |
| víz | vizet | water (ACC) |
| kenyér | kenyeret | bread (ACC) |
| leves | levest | soup (ACC) |
| hús | húst | meat (ACC) |
| csirke | csirkét | chicken (ACC) |
| alma | almát | apple (ACC) |
| tea | teát | tea (ACC) |
| sütemény | süteményt | cake (ACC) |

## 3️⃣ Ordering food – **Kérek** / **Kérnék**

### **Kérek** = I would like / I'll have (informal request)

* **Kérek egy kávét.**
  I'd like a coffee.

* **Kérek egy levest és egy főételt.**
  I'd like a soup and a main course.

### **Kérnék** = I would like (more polite/formal)

* **Kérnék egy pohár vizet.**
  I'd like a glass of water.

* **Kérnék egy bort.**
  I'd like a wine.

### Structure: **Kérek / Kérnék + egy + [noun in accusative]**

| Order | Hungarian | English |
| ----- | --------- | ------- |
| a coffee | Kérek egy kávét. | I'd like a coffee. |
| a soup | Kérek egy levest. | I'd like a soup. |
| a beer | Kérek egy sört. | I'd like a beer. |
| the bill | Kérem a számlát. | The bill, please. |

---

## 4️⃣ **Szeretem** vs **Szeretek**

This is an important distinction in Hungarian!

| Form | When to use | Example |
| ---- | ----------- | ------- |
| **Szeretem** | I like it (a specific thing) — definite | Szeretem a kávét. (I like coffee.) |
| **Szeretek** + infinitive | I like to do something | Szeretek kávézni. (I like drinking coffee.) |

### More examples:

* **Szeretem a bort.** → I like wine. (wine in general, definite)
* **Szeretem ezt a levest.** → I like this soup. (this specific soup)
* **Szeretek főzni.** → I like to cook.
* **Szeretek étterembe menni.** → I like going to restaurants.

## 5️⃣ Asking about price

* **Mennyibe kerül?** – How much does it cost? (singular)
* **Mennyibe kerülnek?** – How much do they cost? (plural)
* **Mennyibe kerül a kávé?** – How much does the coffee cost?
* **Ez mennyibe kerül?** – How much does this cost?

## 8️⃣ Model dialogues

### Dialogue 1: Ordering at a restaurant

**Felszolgáló:** Jó estét! Mit kérnek?
**Vendég A:** Kérek egy gulyáslevest és egy csirkét rizzsel.
**Vendég B:** Én kérnék egy salátát és egy pohár bort.
**Felszolgáló:** Milyen bort kér? Fehéret vagy vöröset?
**Vendég B:** Fehéret kérek, köszönöm.
**Felszolgáló:** Rendben, mindjárt hozom.

*Waiter: Good evening! What would you like?*
*Guest A: I'd like a goulash soup and a chicken with rice.*
*Guest B: I'd like a salad and a glass of wine.*
*Waiter: What wine would you like? White or red?*
*Guest B: White, please.*
*Waiter: Of course, I'll bring it right away.*

---

### Dialogue 2: Paying the bill

**Vendég:** Elnézést! Kérem a számlát.
**Felszolgáló:** Igen, azonnal. Tessék, itt a számla.
**Vendég:** Mennyibe kerül?
**Felszolgáló:** Összesen négyezer-ötszáz forint.
**Vendég:** Köszönöm. Finom volt minden.
**Felszolgáló:** Köszönjük, jöjjenek vissza!

*Guest: Excuse me! The bill, please.*
*Waiter: Yes, right away. Here is the bill.*
*Guest: How much is it?*
*Waiter: Four thousand five hundred forints in total.*
*Guest: Thank you. Everything was delicious.*
*Waiter: Thank you, please come back!*

## 9️⃣ Key grammatical points

### The accusative -t suffix

| Type | Vowel harmony | Suffix | Example |
| ---- | ------------- | ------ | ------- |
| ends in vowel | — | **-t** | kávé → kávét |
| ends in consonant, back vowels | a, o, u | **-ot / -t** | bor → bort |
| ends in consonant, front vowels | e, i, ö, ü | **-et / -öt** | sör → sört |

### Ordering formula:
> **Kérek / Kérnék + egy + [accusative noun]**

### Definite vs indefinite "like":
> **Szeretem** + a + [noun] = I like [specific thing]
> **Szeretek** + [infinitive] = I like to [do something]

## 1️⃣1️⃣ Key points to remember

* The **accusative -t** marks the direct object (what you eat, drink, order)
* Use **Kérek** (casual) or **Kérnék** (polite) to order
* **Szeretem** + noun = I like [a specific thing] — definite conjugation
* **Szeretek** + infinitive = I like to [do something] — indefinite conjugation
* **Mennyibe kerül?** = How much does it cost?
* **Kérem a számlát.** = The bill, please.
* **Jó étvágyat!** = Enjoy your meal!
