# 📘 Lesson 4 – *Mit szeretek csinálni?*

**What I like to do**

## 🎯 Objectives

By the end of this lesson, you'll know how to:

* use **szeretni** (to like/love) in present tense,
* use **tudni** (to know / can) in present tense,
* talk about **your hobbies**,
* use **-val / -vel** (with),
* review the **possessive**,
* better understand **vowel harmony**.

---

## 1️⃣ The verb **szeretni** – "to like/love"

Present tense form (1st person):

> **szeretek** = I like/love

Examples from the texts:

* **Nagyon szeretek sportolni.**
  I really like to play sports.
* **Nagyon szeretek ukulelézni.**
  I really like to play the ukulele.

👉 In Hungarian, you often use an **infinitive verb** after *szeretek*:

> szeret + **verb -ni**

| English | Hungarian |
| -------------------- | ----------------------- |
| to like playing sports | **szeretek sportolni** |
| to like singing | **szeretek énekelni** |
| to like playing piano | **szeretek zongorázni** |

---

## 2️⃣ The verb **tudni** – "to know / can"

> **tudok** = I know / I can
> **tud** = he/she knows/can

Examples:

* **A barátnőm nagyon jól tud pingpongozni.**
  My girlfriend knows how to play ping-pong very well.

| Person | tudni |
| --------- | --------- |
| I | **tudok** |
| you | **tudsz** |
| he / she | **tud** |

---

## 3️⃣ Hobbies from the texts

All hobbies are expressed by **verbs in -ni**:

| Hungarian | English |
| ------------ | ------------------------ |
| sportolni | to play sports |
| pingpongozni | to play ping-pong |
| ukulelézni | to play ukulele |
| zongorázni | to play piano |
| énekelni | to sing |
| zenélni | to make music |
| gyakorolni | to practice |
| fellépni | to perform (in concert) |

---

## 4️⃣ The suffix **-val / -vel** = "with"

You add it to the noun.

| Word | With |
| -------------------- | --------------- |
| barátnőm (my girlfriend) | barátnőm**mel** |
| gitár | gitár**ral** |
| zongora | zongorá**val** |
| ukulele | ukulelé**vel** |

Examples:

* **pingpongozom a barátnőmmel**
* **a barátnőmmel éneklünk**
* **gitárral zenélünk**

---

## 5️⃣ Review: the possessive

| Noun | My |
| ------- | ---------------------- |
| barátnő | barátnő**m** |
| zongora | zongorá**m** |
| ukulele | ukulelé**m** |
| gitár | gitár**ja** (his / her) |

Examples:

* **van egy ukulelém**
* **van egy régi zongorám**
* **a barátnőmnek van egy gitárja**

---

## 6️⃣ Review: vowel harmony

Suffixes change according to the vowels in the word.

| Back vowels | a, o, u, á, ó, ú |
| Front vowels | e, i, ö, ü, é, í, ő, ű |

Examples:

* zongora → zongorá**m**
* gitár → gitár**ja**
* barátnő → barátnő**m**
* ukulele → ukulelé**m**
